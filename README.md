# Ahmed Mustafa — Academic Portfolio

A light, minimal academic/engineering portfolio for GitHub Pages.

## Files
- `index.html` — homepage
- `style.css` — complete responsive visual design
- `script.js` — mobile navigation
- `projects/teknofest.html` — detailed TEKNOFEST page
- `projects/passive-radar.html` — detailed passive-radar page
- `projects/dbfc.html` — detailed DBFC page
- `assets/project.css` — project-page styling

## Local preview
Open `index.html` with VS Code Live Server.

## GitHub Pages
Upload the entire folder to your GitHub Pages repository while preserving the structure. In GitHub, use Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Personal evidence
The site is functional without external image files. The marked image boxes are intentional placeholders for your real photographs/evidence. Replace them with your own images before publishing.
