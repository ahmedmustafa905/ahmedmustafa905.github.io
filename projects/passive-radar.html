Final Year Research Project · Radar & Signal Processing

Drone Detection Using Passive Radar

My final-year project explored radar-based drone detection using software-defined radio and digital signal processing. The work brought together RF hardware, signal acquisition, and range-Doppler processing.

Role: Final Year Project Researcher

RESEARCH QUESTION

The project investigated how reflected radio signals could support drone detection. Its research interest was passive radar; the experimental arrangement described here used an ADALM-Pluto transmitter and a Pluto+ receiver to study signal acquisition and processing.

EXPERIMENTAL SETUP

The experimental setup used ADALM-Pluto for transmission and Pluto+ for signal acquisition. Two Yagi-Uda antennas served the receiver channels, while a helical antenna was used on the transmitter side.

PROCESSING APPROACH

MATLAB configured the transmitter and generated the waveform. A Python pipeline handled receiver IQ data acquisition, preprocessing, and visualization. The work covered FFT-based analysis, cross-ambiguity processing, and range-Doppler representations.

IMPLEMENTATION NOTES

  • Generated an LFM chirp in MATLAB and transmitted it with ADALM-Pluto. The project configuration used a 15 MHz bandwidth and a 2.9 GHz carrier.
  • Acquired reference and surveillance IQ data on Pluto+ through a Python pipeline, with separate receiver-gain settings for the two channels.
  • Applied dechirp processing using the reference and surveillance channels, followed by windowing and range-Doppler processing.
  • Examined range and Doppler resolution in relation to waveform bandwidth and processing duration. These configuration-dependent quantities should be distinguished from measured drone-detection performance.
  • Visualized normalized range-Doppler maps alongside time-domain and spectral views. A displayed range window describes the visualization extent, rather than a verified detection distance.

RESEARCH DIRECTION

The project connected RF hardware, signal processing and an applied detection problem, strengthening my interest in radar, sensing and autonomous systems.
