Further engineering projects

Additional work in machine learning, embedded systems, robotics, and IoT.

Machine learning · Biomedical signals

EEG-Based Eye State Classification

Built a Python pipeline to classify open and closed eye states from multi-channel EEG data. Used filtering and Common Spatial Pattern feature extraction with a Random Forest classifier.

Reported 90% accuracy on a held-out test split.

  • Python
  • CSP
  • Scikit-learn

Embedded systems · Distance measurement

STM32 Proximity & Collision Alerts

Developed an STM32 prototype using an HC-SR04 ultrasonic sensor and input-capture timers for distance measurement. Integrated an OLED display, DFPlayer Mini, and buzzer for audio-visual proximity warnings.

Combined I²C and UART peripherals with C/C++ firmware.

  • STM32
  • C / C++
  • I²C / UART

Mobile robotics · Mechanical design

Line-Following Differential Drive Robot

Designed a robot chassis in SolidWorks and programmed a NodeMCU (ESP8266) controller with an L298N motor driver. Used PWM and differential-drive kinematics for speed and steering control.

Built a functional prototype for indoor laboratory transport.

  • ESP8266
  • SolidWorks
  • PWM

IoT · Embedded automation

IoT Water Tank Management

Developed an ESP32-based system for liquid-level measurement and threshold-based pump control using an ultrasonic sensor and relay. Added MQTT telemetry and a Node-RED monitoring dashboard.

Integrated water-level monitoring, pump control, and Wi-Fi reporting.

  • ESP32
